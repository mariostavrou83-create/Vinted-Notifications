Finder Home Companion

1. Unzip the download. In Google Chrome, open chrome://extensions, turn on Developer mode, choose Load unpacked and select the folder containing manifest.json.
2. In Finder's Connections page create a Home source and its one-time pairing code. Open the buying account's Vinted UK homepage in that Chrome profile. Open Vinted’s account menu if its own profile link is hidden.
3. Open Finder Home Companion, enter the pairing code and choose Pair this Chrome profile. Choose Watch this Home tab. Leave the signed-in Home page visible while sourcing.
4. Open the companion to see the last observation and delivery status or to stop. Each Chrome profile pairs separately. Revoke a source in Finder Connections to end its server access.

The companion reads the personalised listing cards Vinted displays in the selected Home tab and submits eligible fresh items to the dashboard that supplied this ZIP. It skips sold or unavailable items and unverified upload times. A quiet feed or cards without a qualifying timestamp can produce zero alerts. Choose Resume to watch the same signed-in profile again when you next open its Home in Chrome. Stop watching removes this permission. The regular Finder dashboard controls recipients.
