Set up Finder in Chrome

Connect the Chrome profile you use for buying on Vinted UK.

Install the extension

Download the ZIP and extract its contents to a folder you can keep on this computer.

Download Chrome extension ↓

Load it in Chrome

Open chrome://extensions, switch on Developer mode, choose Load unpacked and select the folder containing manifest.json. Pin Finder using Chrome’s Extensions menu.

Pair your buying profile

Sign in to Vinted UK and Finder in the same Chrome profile. In Finder, open Chrome checkout and get a pairing code. Open the extension on that Finder tab, select Pair this Finder tab and follow the account confirmation.

Start watching listings

On your Vinted Home page, open Finder and select Watch this Home tab. To follow a saved search, open its Vinted catalogue from Saved searches and select Watch this saved search. Finder checks what Chrome displays every second on Home and every five seconds on a saved search. Background tabs can update more slowly.

Share Home alerts with Telegram

Use a separate Chrome profile signed in to each Vinted account you want to watch. Open Home sharing in the recipient’s Finder account to create a recipient code. In the Finder account paired to the source Home, enter the code and choose Share Home alerts. Repeat for other Homes or recipients.
