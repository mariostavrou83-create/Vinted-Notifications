For each new alert

  1. Choose your category, brand, sizes and other filters on eBay UK as usual.
  2. While that filtered eBay page is open, use your saved Send filters to MSJ bookmark.
  3. The dashboard opens a new form with the eBay filter link filled in. Add your Vinted link, shared keywords, exclusions and complete budget, then save.

The helper reads only public search-filter metadata already on that page. It makes no eBay request and transfers no account cookies, tokens or passwords. It creates an unsaved form and cannot buy an item. If it can't confirm the filters, it stops instead of guessing.
